3. New file: k8s/jenkins-rbac.yaml

Lets the jenkins service account start agent pods in the observability namespace.

apiVersion: rbac.authorization.k8s.io/v1
kind: Role
metadata: {name: jenkins, namespace: observability}
rules:
  - apiGroups: [""]
    resources: [pods, pods/exec, pods/log, services, endpoints, configmaps, secrets, persistentvolumeclaims]
    verbs: [get, list, watch, create, delete, patch, update]
  - apiGroups: [apps]
    resources: [deployments, replicasets]
    verbs: [get, list, watch, create, delete, patch, update]
---
apiVersion: rbac.authorization.k8s.io/v1
kind: RoleBinding
metadata: {name: jenkins, namespace: observability}
subjects: [{kind: ServiceAccount, name: jenkins, namespace: observability}]
roleRef: {kind: Role, name: jenkins, apiGroup: rbac.authorization.k8s.io}

Alloy regex (in logging/alloy-config.yaml), with the group names kept:

expression = "/var/log/containers/(?P<pod>[^_]+)_(?P<namespace>[^_]+)_(?P<container>.+)-[0-9a-f]{64}[.]log"
# alloy-daemonset.yaml args also include:
#   - --server.http.listen-addr=0.0.0.0:12345
# demo-app/deployment.yaml exporter image: localhost:32000/nginx-exporter:lab

5. Verify
sudo microk8s kubectl get pods -n observability
sudo microk8s kubectl logs deploy/loki -n observability | grep "started"
sudo microk8s kubectl logs daemonset/alloy -n observability | grep "loki"
sudo microk8s kubectl logs deploy/demo-app -n observability -f
Open on your computer:
  Demo app    http://127.0.0.1:30080/
  Prometheus  http://127.0.0.1:30334   (all targets should be UP)
  Grafana     http://127.0.0.1:30300/  (admin / admin)

Grafana -> Explore -> Loki (one query per pod):
  count_over_time({namespace="observability", pod=~"demo-app-.*"} |= " 200 "[1m])
  count_over_time({namespace="observability", pod=~"demo-app-.*"} |= " 404 "[1m])

Dashboard: Grafana → Dashboards → Import → Upload JSON (use the dashboard JSON file from the lab repo).

6. Jenkins
sudo microk8s kubectl get svc jenkins -n observability
# NAT: open http://127.0.0.1:32043 on your computer (bridged: http://<VM_IP>:32043)

sudo microk8s kubectl get pods -n observability
sudo microk8s kubectl exec -it deploy/jenkins -n observability -- cat /var/jenkins_home/secrets/initialAdminPassword
# Username: admin   Password: <the value printed above>

# Check the volume is Bound (keeps jobs and passwords across restarts)
sudo microk8s kubectl get pvc -n observability

On first run Jenkins may say it appears to be offline: click Skip plugin installations (the plugins are already installed).

# Jenkins will not load?
sudo startJenkinsLabDHCPcerts      # bridged networks: the VM's IP changed
# Last resort:
sudo microk8s refresh-certs --cert server.crt
sudo microk8s stop
sudo microk8s start
